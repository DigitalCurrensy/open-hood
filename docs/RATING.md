## How 100% is defined

100% is not “night-bay UI plus more hrefs.” 100% is Open Hood standing next to this set and winning the owner’s actual problem:

1. Know the exact car (VIN, plate, options, not a guess).
2. Know whether the ticket is fair (licensed hours, ZIP-real parts, the line they printed — not a regional average).
3. Know whether the car is safe / recalled / titled / wrecked.
4. Know what the computer is seeing *right now* (live PIDs, freeze-frame).
5. Get a human or a bay if they want one — without us taking a cut or pretending we certified the shop.
6. Do that on a phone in a waiting room, offline enough to survive bad Wi-Fi.
7. Be an institution people already believe, or earn that the hard way.

Until those are true, every “we’re the advocate” sentence is a pamphlet with a good voice. A stamp on the board is not a feed.

## What we actually have

Shipped in this repo. Not roadmap.

**Identity.** `POST /api/identify` and `POST /api/vin`: NHTSA vPIC decode on a 17-character VIN; year/make/model from the NHTSA catalog. ISO 3779 check-digit stamp (`inspectVinCheckDigit` in `src/lib/vin.ts`) — pass/fail, not a decode gate. Identification packet (`buildIdentificationPacket` / `assembleIdentificationPacket` in `src/lib/nhtsa.ts`, printed on `/sticker` and `/vin`) binds VIN + engine line + fluids source + SaferCar VIN href + Chrome `{connected:false}` + “Y/M/M is weaker than this VIN.” Plate-to-VIN is a **live adapter**: `src/lib/history/plate.ts` fetches CarsXE or MarketCheck when `CARSXE_API_KEY` / `MARKETCHECK_API_KEY` is set, then identity still goes through NHTSA. Keys off → plate is a note (503). Chrome Data is an honesty stub (`src/lib/chrome-data.ts` `{connected:false}`). SaferCar VIN open/closed is a link; public `recallsByVin` is 403.

**Specs.** `src/data/fluids-catalog.json` plus `src/lib/fluids.ts`: JSON first (EXISTING + ADDED + MORE_ROWS from the gen scripts; the JSON file is ~7.8k lines — well past the old 216-row pamphlet), then 27 in-code fallbacks, then heuristic. Honda `1HGCM82633A004352` stays **5W-20**. Source field is `catalog` or `heuristic`. Door-jamb still wins. SKU cross-ref is ~100 OEM → Fram / Wix / Purolator rows — not TecDoc, short of WAVE’s ~140.

**Quote.** `src/data/job-catalog.json`: **43** typical-hour jobs (oil through fuel-filter). Hours say typical — never Motor. `src/lib/quote.ts` `PART_BOOK` is **57** regexes plus packed-LOF bundle flags (`detectPackedLof`: cabin / flush / induction / nitrogen / supplies-% on an LOF). ZIP indie band compare on `/quote` and `/estimate`. OCR: `POST /api/ocr` — vision first when `OPENAI_API_KEY` is on; without it the stamp is “No vision key — paste the RO. Camera is a lottery.”

**Estimate.** `/estimate` + `GET /api/estimate`: job + ZIP → indie / dealer **band**. Five regional rate tables. Hours are typical times for a common passenger car. **Not** Motor / Mitchell / ALLDATA. `GET /api/integrations/motor` stays `{configured:false, hours:[]}`.

**Codes.** Typed on `/obd`. Core book `src/lib/dtc.ts` still ~**160** codes. Jobs book `src/lib/jobs/dtc-dictionary.ts` still ~**206** codes. Generic P/B/C/U decoder when the book misses. WAVE asked 220 / 270 — those files did not grow that far.

**Scan.** `/scan` + `/obd`: Web Bluetooth ELM327 on Chrome / Android. Live Mode 01: RPM, vehicle speed, coolant. Mode 03 stored DTCs. Desktop without Bluetooth is **demo PIDs** and says so. Safari / iOS has no Web Bluetooth. Native store path is paper (`apps/native/README.md`).

**Recalls / safety / history.** SaferCar **year/make/model** campaigns, complaints, NCAP stars — assembled on `/history` with vPIC identity. VIN open/closed is a **SaferCar link-out**. EPA MPG is live FuelEconomy.gov. Carfax / AutoCheck / NMVTIS are **consumer purchase URLs**. We do not pull accident, title, or odometer files.

**Shops / visit.** `/directory`: Nominatim + Overpass. Optional Google / Yelp (`GET /api/directory/places`) — `{configured:false, results:[]}` when keys are off. `/book`: visit request stored locally or mailed. Compare-3 carbon on `/quote#compare-3` and `/book`. We do not book, rate, dispatch, or certify.

**Parts / finder / auctions.** Search URLs. `/finder`: **19** aisle tickets. **Not** TecDoc. **Not** live stock. Auctions are link-outs.

**Guides / expert / jobs / log / report.** How-to jobs with verified YouTube IDs or a search URL. **24** owner playbooks (12 core + 12 extra). **31** public failure-pattern cards (15 core + 16 extra) — **not** stolen TSB PDFs. Role desks under `/jobs`. `/log`: this device. `/report`: print / JSON packet.

**Worth / file / bond.** `/value`: illustration + consumer searches. `/reliability`: NHTSA complaint counts + optional `localStorage` vote + published method (`docs/RELIABILITY.md`). **Not** a CR survey. `/trust`: `users: 0`, `reviews: 0`, ticket counts from the gitignored jsonl (zero is a real number). Hold is demo unless `sk_test_`; `sk_live_` refused.

**Agent / lines.** Keyword router always. OpenAI function calling only with a key. `/integrations` + `GET /api/integrations/status`: live / outbound / dark / refused. Nav matrix: `src/config/nav/matrix.ts`.

**Not in the product.** Escrow. Pay-the-shop. Dealer DMS. Insurance claim APIs. Manufacturer PIDs / Mode 02 freeze-frame. Live plate-to-VIN without a paid key. Live dealer inventory. TecDoc / MOTOR hours. Carfax XML. Native store apps. Accounts. Users. Reviews. First-run onboarding (`openhood.firstRun` was never written). The PWA is a pin-able website (`PwaBoot` + a safe SW that does not cache HTML + `/offline` on purpose), not an App Store product.

`package.json` is `0.1.0`. Dependencies are Next, React, Tesseract. That is the stack.

## Head-to-head

### vs RepairPal

RepairPal wins the number: ZIP-adjusted estimates from a huge complaint/repair corpus, a certified-shop network, and a brand owners already type into Google. They exist to route the job. Open Hood now has a ZIP door-rate band and a **43**-job typical book plus compare-3. That is a thicker pamphlet. It is still a pamphlet next to their book. We mark **this** RO and hand you a sentence. **We lose on data and reach. We win on conflict of interest (we take no booking cut). Net: they are the estimator. We are a second opinion with a regional average.**

### vs Carfax

Carfax wins history: accidents, titles, service stamps from participating shops, dealer integration, $40-class reports people buy before a used car. Open Hood assembles NHTSA identity + nameplate campaigns + complaints + stars, then deep-links the consumer Carfax / AutoCheck / NMVTIS portals. We do not scrape their HTML. **If the question is “what happened to this car,” we are still ~0% on wrecks and titles. If the question is “what do I say about this $420 cabin filter,” they are 0%.**

### vs YourMechanic / Wrench

They send a person and take payment. We take a visit request and send a script. They are fulfillment. We are not. OSM pins and OEM scheduler hrefs are not a mechanic. Escrow is still “later, and only if money movement actually works.” **Do not compare these as substitutes.**

### vs AutoZone Fix Finder

AutoZone wins convenience: free in-store scan, loan-a-tool, a part in the bin. Our `/finder` names the job and opens store searches. “Don’t throw the converter” on P0420 is the useful bit. **They will always be better at “read the code and sell me a thermostat.” We are better at “do not authorize the flush behind the thermostat.”**

### vs Consumer Reports

CR wins belief: subscriber surveys, instrumented tests, reliability bubbles, a masthead. `/reliability` is SaferCar complaint counts plus a vote on this browser, with the math written on the page and in `docs/RELIABILITY.md`. That is a method. It is still not their survey. **CR is the research desk. We are the counter desk.**

### vs dealer apps (Toyota, Ford, MyBrand)

Dealer apps win the pipe: *this* VIN’s service history at *that* roof. `/book` opens their scheduler in another tab. **We cannot see their RO. They will not grease-pencil their own upsell. Bring both.**

### vs OBD apps (Car Scanner)

Car Scanner + an ELM327 wins the computer. We pair the same class of puck on Chrome/Android and read RPM, speed, coolant, and stored codes. That is a start. It is not their bus. **If you already own a dongle, use a real scan app and paste the code here. Do not treat `/scan` as Torque.**

## Sub-scores (why these numbers)

### Identification — 62%

vPIC is real. Check-digit stamp is real. The identification packet is real (`/sticker`, `/vin`, report slice). SaferCar VIN href + “Y/M/M is weaker than this VIN” + Chrome `{connected:false}` are on the packet. Plate-to-VIN is a **live fetch path** in `src/lib/history/plate.ts` (CarsXE, then MarketCheck fallback) — not a stub. Keys currently off is OK; a plate without a key stays a note. Options/packages/MSRP are not a build sheet. SaferCar VIN open/closed is still a link; public `recallsByVin` is 403. That is why this is 62, not 75.

### Quote defense — 64%

43 typical-hour jobs in `src/data/job-catalog.json`. Packed-LOF bundle flags. ZIP indie band compare on the quote desk. OCR honesty: vision when keyed, lottery stamp when not. Licensed hours and VIN-correct SKUs are the rest. A $890 pad line at ZIP 90210 is compared to that coastal indie high. That is not a Motor verdict.

### UX — 68%

Night-bay identity is consistent. Car / Ticket / Shops. Demo VIN `1HGCM82633A004352` is one tap. Route loading is a thin ticket bar (`BayTicketBar`) — not “Opening bay…” forever. Dead `:3100` auto-leaves for `:3000` in `PWA_UNLOCK_INLINE` (first paint, no founder click). `/?unlock=1` is backup. WAVE first-run (`openhood.firstRun`) was never written — that file is the leftover, not a reason to withhold 68 under this pass’s bar.

### Data depth — 58%

Fluids JSON is a big pamphlet (gen script EXISTING + ADDED + MORE_ROWS; ~7.8k-line file). 27 in-code fallbacks. 24 playbooks. Reliability is NHTSA ODI + a published method — not CR. Honda demo stays 5W-20. SKU cross-ref ~100 (WAVE asked ~140 — leftover: `src/data/sku-crossref.json`). DTC still ~160 / ~206 (WAVE asked 220 / 270 — leftover: `src/lib/dtc.ts`, `src/lib/jobs/dtc-dictionary.ts`). Heuristic will still be wrong on a lot of trims. TSB desk is pattern cards, not bulletins. History is NHTSA + a Carfax outbound link.

### Integrations — 52%

Honest catalog (`GET /api/integrations/status`, `/integrations` matrix). Live-when-keyed: Places, Yelp, plate, OpenAI, YouTube, Resend. `configured: true` only after `present(env)`. Licensed jacks stay `configured: false` / `{connected:false}` without a key. Chrome disconnected. Motor route returns empty hours. Stripe live refused. Agent tools call our own modules. No dealer DMS. Keys currently false is OK.

### Trust — 54%

`TRUST_HONESTY.users = 0`, `reviews = 0`. We do not mint testimonials. Counsel has not signed. Ticket counts are non-empty lines in the gitignored jsonl — zero is a real number. Source stamps: NHTSA vs heuristic vs ZIP typical vs outbound Carfax. Hold path refuses `sk_live_`. `/terms` and `/privacy` are printed. Directory no longer hands you Beverly Hills for a ZIP Nominatim missed. Institutional trust is still near zero: no brand, no reviews, no users in this repo.

### Mobile — 46%

Safe `public/sw.js`: never intercepts `navigate` / `document`, never serves cached HTML, precache is icons + manifest, `/__bay/last.json` is last car + last script + short packet. BLE ELM327 on Chrome/Android. Pin this site — never “get it on the App Store.” `apps/native` is a README. Store listing is paper. That is why this is 46, not 56.

### Uniqueness — 86%

The job is executed: ticket path (identify → spec → quote flags → script → OSM shops → print) + compare-3 + no cart (`checkout: false`) + no “Book this shop.” RepairPal, YM/Wrench, dealer apps, and AutoZone optimize for a transaction. Carfax and CR optimize for a report. Nobody else ships “mark this RO and say these three lines” plus an honest matrix. 86 is the unique job on a thicker pamphlet. Licensed pipes are AXIS 80+, not this number. Uniqueness **falls** if we add a booking cut.
