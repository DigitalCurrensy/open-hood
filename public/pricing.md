# Pricing — Open Hood

## Free

- Price: $0
- Account: none
- What you get: VIN decode, spec card, quote markup, counter script, guides, OSM directory, OBD translator, estimate ZIP bands
- What you do not get: shop booking, Carfax, Motor / TecDoc hours, live dealer inventory, a certified-shop network

There is no Pro tier on this bay. Optional photo reading and mail need operator keys. If a key is missing, the desk says so instead of inventing a result.
